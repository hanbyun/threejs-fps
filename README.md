DUSTLINE is a round-based tactical FPS in three.js: Vanguard vs Wardens, first to 7 rounds (max 12), with a buy economy, four guns plus a knife, frag / flash / smoke grenades, a plant/defuse spike objective and bot squads that patrol, hold and push across a two-site dusk depot map.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
